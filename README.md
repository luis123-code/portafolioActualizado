# Frontend Showcase

Crea un portafolio profesional para un desarrollador frontend, con diseño moderno, minimalista y responsive (mobile-first). Usa una paleta de colores oscura con un color de acento vibrante (azul o verde), tipografía sans-serif limpia (tipo Inter o Poppins), y animaciones fluidas en toda la página (fade-in, slide-up, parallax sutil, hover states con transiciones suaves).

ESTRUCTURA DE SECCIONES (single-page con navbar sticky y scroll suave a cada sección):

1. HERO / INICIO

- Nombre completo y título profesional ("Frontend Developer")

- Frase corta de presentación (ej: stack principal, enfoque, años de experiencia)

- Texto animado tipo "typewriter" que rote entre roles/tecnologías (ej: "Frontend Developer", "React Enthusiast", "UI/UX Focused")

- Botón CTA principal "Ver proyectos", botón secundario "Contáctame" y botón "Descargar CV" (con ícono de descarga)

- El botón "Descargar CV" debe descargar un archivo PDF (dejar placeholder tipo /cv.pdf que yo reemplace después) y tener un pequeño efecto hover (ej: leve escala o cambio de color)

- Foto de perfil o ilustración/avatar con animación de entrada (fade + escala)

- Iconos de redes sociales (GitHub, LinkedIn, correo) con efecto hover animado

2. MÉTRICAS / ESTADÍSTICAS

- Barra o sección con 4 tarjetas/números destacados en línea, con animación de conteo ascendente al entrar en el viewport (usar Intersection Observer o similar)

- Ejemplos de métricas a incluir (con placeholders editables):

  - Proyectos completados (ej: "12+")

  - Años de experiencia (ej: "2+")

  - Certificados obtenidos (ej: "8+")

  - Tecnologías dominadas (ej: "10+")

- Diseño simple con ícono, número grande y etiqueta debajo, con efecto hover leve en cada tarjeta

3. SOBRE MÍ

- Breve biografía profesional (3-4 líneas)

- Lista de tecnologías/skills con iconos (React, JavaScript, TypeScript, HTML, CSS, Tailwind, Git, etc.), organizadas en tarjetas o badges con animación de aparición escalonada (stagger) al hacer scroll

4. GITHUB / ACTIVIDAD

- Sección dedicada a mostrar actividad de código, con:

  - Tarjeta de perfil de GitHub (avatar, username, bio corta, botón "Ver perfil completo")

  - Grid de estadísticas tipo GitHub stats card (repositorios públicos, seguidores, contribuciones del último año, lenguaje más usado) — usar placeholders numéricos editables o dejar espacio preparado para conectar con la API pública de GitHub más adelante

  - Gráfico o representación visual del "contribution graph" (puede ser un componente simulado tipo heatmap con datos placeholder)

  - Animación de entrada tipo fade/slide al hacer scroll a esta sección

5. PROYECTOS

- Grid de tarjetas (cards) responsive, 3 columnas en desktop, 1 en mobile

- Cada tarjeta debe incluir:

  - Imagen/screenshot del proyecto con efecto hover de zoom suave

  - Nombre del proyecto

  - Breve descripción (2 líneas)

  - Tecnologías usadas (badges pequeños)

  - Métricas de impacto del proyecto cuando aplique (ej: "40% menos tiempo de carga", "+500 usuarios activos", "Lighthouse Score: 95/100")

  - Botones "Ver demo" y "Ver código" (GitHub)

- Animación de aparición escalonada (stagger) al hacer scroll, y efecto hover con leve elevación/sombra en las tarjetas

- Dejar 4-6 proyectos de ejemplo con contenido placeholder que yo pueda editar después

6. CERTIFICADOS

- Sección separada tipo galería/carrusel o grid de tarjetas, con animación de aparición al hacer scroll

- Cada certificado debe mostrar:

  - Imagen o ícono del certificado

  - Nombre del curso/certificación

  - Institución que lo emitió (ej: Platzi, Coursera, freeCodeCamp, etc.)

  - Fecha de obtención

  - Botón "Ver certificado" que abra el PDF/imagen en una nueva pestaña o modal (con animación de apertura del modal)

- Dejar 4-6 certificados de ejemplo con contenido placeholder

7. CONTACTO

- Formulario profesional y funcional con los campos:

  - Nombre completo (requerido)

  - Correo electrónico (requerido, con validación de formato)

  - Asunto

  - Mensaje (textarea, requerido)

  - Botón "Enviar mensaje" con estado de carga (loading animado) y mensaje de confirmación de envío exitoso o error (toast o alerta animada)

- Validación de formulario antes de enviar (campos vacíos, formato de email), con animación sutil de "shake" en campos con error

- Debajo o al lado del formulario, mostrar también: correo directo, LinkedIn y GitHub como alternativa de contacto, además del botón de "Descargar CV" nuevamente

8. FOOTER

- Copyright con año actual

- Links a redes sociales con hover animado

- Link de vuelta al inicio (botón flotante "volver arriba" que aparece al hacer scroll, con animación suave)

REQUISITOS TÉCNICOS:

- Totalmente responsive (mobile, tablet, desktop)

- Modo claro/oscuro (toggle con animación de transición suave entre temas)

- Barra de progreso de scroll en la parte superior de la página (indicador visual de cuánto se ha scrolleado)

- Optimizado en velocidad de carga, sin abusar de animaciones pesadas

- Accesible (buen contraste, textos alt en imágenes, navegación por teclado, respetar prefers-reduced-motion para usuarios que prefieran menos animación)

- Código limpio y componentizado para que pueda editar fácilmente textos, imágenes, links, métricas y el archivo del CV después

TONO Y ESTILO GENERAL:

- Profesional, serio, orientado a reclutadores y clientes potenciales

- Animaciones que aporten dinamismo sin distraer ni sentirse recargadas

- Foco en mostrar el trabajo y los resultados con claridad
